# X52 Pro — шпаргалка EDActivityOverlay

Актуально для профиля Logitech `X52ProEliteV223EX_Overlay.pr0` и пресета Elite
`X52ProElite v2.2.3 FIXED`.

## Важно перед полётом

- В Logitech G/X52 загрузить `X52ProEliteV223EX_Overlay.pr0`.
- В Elite выбрать пресет `X52ProElite v2.2.3 FIXED` для общего управления,
  корабля и ТРП.
- Для работы ускорения на кнопке **i / Clutch** открыть `Win+R` → `joy.cpl` →
  **X52 Professional H.O.T.A.S.** → **Свойства** → вкладка **MFD** и отключить
  **Enable Clutch Mode / Включить режим сцепления**. Иначе драйвер перехватывает
  кнопку до того, как профиль сможет отправить `Tab`.
- Правое колесо MFD зарезервировано приложением: вращение меняет помощника,
  одиночное нажатие включает/выключает интерактивный фокус, двойное скрывает
  или возвращает все оверлеи.

## Управление ED Inara Overlay

| Орган X52 | Действие |
|---|---|
| Правое колесо MFD вверх / вниз | Предыдущий / следующий вид деятельности |
| Одиночное нажатие правого колеса | Включить / выключить интерактивный фокус |
| Двойное нажатие правого колеса | Скрыть / вернуть все оверлеи |
| Mouse Pointer на РУД | Перемещение курсора через штатный профиль X52 |
| Mouse Click на РУД | Левый клик через штатный профиль X52 |

Для мини-джойстика на РУД в Logitech/Saitek Profiler должны быть назначены
`Mouse X Axis` и `Mouse Y Axis`. Приложение больше не двигает курсор через
цифровой POV 1 и не синтезирует клики через Fire A: курсор и левый клик
полностью оставлены штатным `Mouse Pointer` / `Mouse Click` профиля X52.

## Оверлей

| Управление | Действие |
|---|---|
| Правое колесо MFD вверх/вниз | Предыдущий/следующий помощник |
| Одиночное нажатие правого колеса MFD | Интерактивный фокус |
| Двойное нажатие правого колеса MFD | Скрыть/вернуть все оверлеи |
| Mouse Pointer на РУД | Курсор |
| Mouse Click на РУД | Левый клик |
| `Ctrl+6` | Резервное переключение интерактивного режима |

Опасное назначение: **Mode 2 + Pinkie + Toggle 6** сбрасывает весь груз.
Перед использованием макросов стыковки и внешних команд стоит проверить их один
раз на стоянке: они зависят от текущей раскладки клавиатуры и состояния интерфейса.
